## Research focus

**M.Sc. Electrical Engineering (thesis), University of Manitoba** — decision-aware world models for decentralized mobility and resource control in multi-UAV networks. **B.E. Electrical Engineering, NUST** — senior thesis on real-time multi-agent reconfigurable intelligent surface optimization for 6G networks.

My central research theme is **agentic AI for wireless networks**: autonomous agents that perceive network state, coordinate with one another, and allocate radio resources under real-world constraints. Published in IEEE WCNC, IEEE Network, and IEEE GLOBECOM Workshops, with additional manuscripts under review.

## Agentic AI systems

| | System | Description |
|---|---|---|
| 🤖 | **MAFRO** — multi-agent RIS optimizer | Retrieval-augmented coordinator–evaluator agents optimizing sum-rate, fairness, and energy efficiency in RIS-assisted 6G networks. Evaluated against gradient-descent, alternating, and manifold-optimization baselines. → *IEEE WCNC 2026 (first author)* |
| 📡 | **ACP-N** — agentic communication protocol | Distributed agents coordinating RIS and NOMA resource allocation in dynamic next-generation networks. → *IEEE Network 2026 (first author)* |
| 🛠️ | **ACP-T** — protocol implementation | Open implementation of the telecommunications multi-agent communication protocol behind the ACP-N research line. → *[GitHub](https://github.com/Ashar-Javid/ACP-T)* |
| 🎓 | **AgenticAI Workshop** — multi-agent pipelines | End-to-end pipeline patterns for building and evaluating multi-agent systems. → *[GitHub](https://github.com/Ashar-Javid/AgenticAI_Workshop)* |
| 🏭 | **Smart Trace** — agentic design automation, Korea EHT | Multimodal large language model agents automating electric heat-tracing design from AutoCAD drawings with retrieval-augmented memory. Reduced engineering design-cycle time by over 90 percent. Showcased at ADIPEC 2025. |
| 🌊 | **Seismic graph networks** — University of Alberta | Spherical graph neural network with Chebyshev convolutions and BiLSTM for seismic-wave early earthquake detection. MSE 0.17 / MAE 0.30 on USGS and IRIS datasets. → *Mitacs Globalink 2025* |
