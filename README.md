## Professional Summary

**MSc Electrical Engineering (thesis), University of Manitoba (2026–Present)** — decision-aware world models for decentralized mobility + resource control in multi-UAV networks.
**BE Electrical, NUST (2022–2026, CGPA 3.64/4.00)** — senior thesis: real-time RIS optimization for 6G with a multi-agent framework.

I build where **AI meets wireless**: multi-agent RIS optimization (**MAFRO**), agentic communication protocols (**ACP-N / ACP-T**), LLM-orchestrated resource allocation, and decentralized UAV control — validated at **HPC scale on the Alliance Rorqual cluster (H100 GPUs, Slurm arrays)** and published at **WCNC, IEEE Network, GLOBECOM**.
Previously **AI Engineer @ Korea EHT** (Smart Trace, −90% design time, ADIPEC 2025), **CTO @ E-Deviser** (8-dev team), **Founder @ XploreBot** (NIC-incubated), **Mitacs Globalink intern @ U. Alberta**.
